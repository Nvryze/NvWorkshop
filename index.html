Tentang Proyek Ini

Website ini dibuat sebagai repositori sederhana untuk menyimpan dan membagikan hasil kompilasi Custom ROM dan Recovery yang saya kerjakan. Tujuannya adalah memudahkan pengguna untuk mengakses file terbaru tanpa harus mencari di forum yang berantakan.

Disclaimer: Semua file yang tersedia di sini bersifat "Flash at your own risk". Saya tidak bertanggung jawab atas kerusakan perangkat (brick) yang mungkin terjadi akibat kesalahan prosedur flashing oleh pengguna. Pastikan Anda sudah membaca panduan dengan teliti sebelum melakukan instalasi.

File disimpan menggunakan layanan pihak ketiga (MediaFire) untuk menghemat bandwidth server utama.
